# AeroBadge S3 - Cyberpunk Voice-Badge & Off-Grid Walkie-Talkie

A standalone, wearable cyberpunk voice-badge and off-grid walkie-talkie powered by ESP32-S3 and NRF24L01+. 
Featuring onboard Li-Po battery management, MicroSD storage, and an I2S audio subsystem for ultra-low latency peer-to-peer voice streaming, audio logging, and offline smart commands without internet.

## Features
- Ultra-low latency voice streaming over NRF24L01+
- I2S Audio Subsystem (INMP441 Mic + MAX98357A Amp)
- Onboard MicroSD card support for audio logging
- Battery charge management system
